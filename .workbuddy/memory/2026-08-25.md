## Agnes AI API 关键事实（下次再写相关代码可直接复用）
- Base URL：`https://apihub.agnes-ai.com/v1`，认证 `Authorization: Bearer <KEY>`，OpenAI 兼容
- 平台注册（免费 100 credits）：`https://platform.agnes-ai.com`
- 文本：`POST /chat/completions`，模型 `agnes-2.5-flash`（钱总监提供）
- 图片：`POST /images/generations`，模型 `agnes-image-2.1-flash`；参数 `{model, prompt, size, ratio, n}`，size 支持 1K/2K/3K/4K + 1024x768 等旧值，ratio 有 1:1/3:4/4:3/16:9/9:16/2:3/3:2/21:9；返回 `data[0].url` 或 `data[0].b64_json`
  - **坑**：文生图不要传 `extra_body.response_format`（仅图生图支持）
- 视频：`POST /videos` 创建 → 返回 `task_id`；`GET /videos/{task_id}` 轮询；模型 `agnes-video-2.5-flash`
  - 参数 `{model, prompt, width, height, num_frames, frame_rate}`，默认 1152x768，帧数需满足 8n+1 且 ≤441
  - 时长换算：~5s=121帧/24fps；~10s=241帧/24fps；~18s=441帧/24fps
  - **坑**：视频 URL 实际字段是 `remixed_from_video_id`，不是文档的 `video_url`，要做兼容
  - 单次生成 2-4 分钟，需异步轮询
