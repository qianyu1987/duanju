## 网站优化（v1.0.42）
### 服务端
- **静态文件 ETag 缓存**：serveStatic 基于 mtime+size 生成 ETag，支持 If-None-Match 304 响应；浏览器刷新不再重复下载 ~142KB HTML
- **HEAD 请求支持**：handleAPI 和 serveStatic 均接受 HEAD，解决此前 HEAD 返回 404 的问题

### 前端
- **Google Fonts 加载优化**：从 CSS `@import`（串行阻塞）改为 `<link rel="preconnect">` + `<link>`，首屏渲染不再等字体文件解析完
