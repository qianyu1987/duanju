## v1.8.1 修复 head style 未闭合 (20:44)

### 根因
- head 里 `<style>` 标签的 `</style>` 在某次编辑中丢失（v1.7.2 补 @media 闭合括号时误写成 `}`）
- HTML 解析器从第13行 `<style>` 进入 RAWTEXT 状态，一路吞掉所有内容
- 唯一剩下的 `</style>` 是 exportAsHtml 模板字符串里那个（约5147行）
- 解析器直到模板里的 `</style>` 才退出 RAWTEXT
- 后果：CSS 不生效、script 标签被当文本、body 首子元素变成模板里的 .header
- 表现："首页乱码"（实际是 JS 源码被当文本 + 样式全无）

### 诊断方法
- 浏览器内 `fetch('/', {cache:'no-store'})` 取原始文本，对比 `document.scripts.length`
- 统计 `<style` vs `</style>` 出现位置（浏览器 eval 中用 matchAll + map index）
- 检查 `document.body.firstElementChild.className`

### 修复
- 把第1495行孤立的 `}` 改为 `</style>`
- 验证：head CSS open=584 close=584 平衡、66916字符（纯CSS）、不含 `<script` 字样

### 教训
- "补全缺失的 }" 修复时，必须先确认缺的是 `}` 还是标签闭合（如 `</style>`）
- 改完必须用浏览器实际渲染验证（curl 看到的 HTML 平衡 ≠ 浏览器解析正确）
- 校验流程：style 标签配对 + 浏览器内 document.scripts.length > 0 + 截图确认
