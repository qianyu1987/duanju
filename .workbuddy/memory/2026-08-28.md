## v1.4 图片动画化（分镜视频生成）

### 功能实现
1. **单镜视频生成** (`generateStoryboardVideo`)
   - 为单个分镜生成短视频（基于参考图）
   - 自动调用视频 API 提交任务
   - 轮询检查生成状态，最多等待 5 分钟

2. **批量视频生成** (`generateAllVideos`)
   - 一键生成所有分镜的视频
   - 进度条显示实时进度
   - 自动跳过已有视频的分镜
   - 失败单个分镜不影响其他分镜继续生成

3. **视频状态追踪** (`pollStoryboardVideo`)
   - 每 5 秒轮询一次 API
   - 更新 UI 显示进度百分比
   - 完成后自动渲染视频播放器

### 技术细节
- 视频生成参数：ratio="9:16", len=5秒
- 参考图作为首帧输入（第一张为主帧）
- 使用 Agnes AI 视频生成 API
- localStorage 存储视频 URL
