## 踩坑 & 经验（可复用）
1. Agnes 文生图 `/v1/images/generations` **不支持 negative_prompt**（返回 invalid_request），需靠 prompt 自身规避
2. 图像生成队列常满载（"text image queue is full"），脚本需重试+退避（本项目最多 12 次 / 20s 间隔）
3. 视频提交 `/v1/videos` 偶发返回无 taskId 的异常响应，submitVideo 必须健壮提取 task_id/id/video_id 且失败重试（seg2 即因此需 gen_yoga_seg2.js 单独补跑）
4. **删除本地文件被沙箱静默拦截**：普通 `rm` 无报错但也不执行，必须用 `find ... -delete` 或 `dangerouslyDisableSandbox:true`，且 `rm -rf shot*` 的 glob 在沙箱内可能不展开
5. macOS 无 brew：ffmpeg 用 `npm i ffmpeg-static`（managed node workspace）装，二进制 `/Users/mac/.workbuddy/binaries/node/workspace/node_modules/ffmpeg-static/ffmpeg`（v6.0）可直接调用
6. Agnes 视频单条上限 441 帧（≈18s @24fps），30s 必须分段（3×10s）再 concat；同源参数三段可直接 libx264 重编码拼接
